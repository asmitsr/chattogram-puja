# চট্টগ্রামের পুজো

চট্টগ্রামের পূজার সম্পূর্ণ বাংলা পাবলিক ওয়েবসাইট। Next.js 14, TypeScript, Tailwind CSS, Supabase (ডেটাবেস + লগইন), Leaflet + OpenStreetMap।

পূর্ণ ধাপে ধাপে গাইড আলাদা পাতায় দেওয়া আছে। এখানে শুধু দ্রুত সারাংশ।

## ফোল্ডারে কী আছে

- `sql/01_policies.sql` : নিরাপত্তা নিয়ম (RLS)। Supabase SQL Editor-এ চালান।
- `sql/02_make_admin.sql` : নিজের ইমেইল দিয়ে অ্যাডমিন বানানো।
- `sql/03_first_year.sql` : (ঐচ্ছিক) প্রথম পূজাবর্ষ।
- `sql/08_comments_remove_news.sql` : (v20) সংবাদ বাদ; মণ্ডপের মন্তব্য, রিপ্লাই ও লাইক।
- `sql/10_admin_only_replies_and_site_likes.sql` : (v29) রিপ্লাই শুধু অ্যাডমিনের; ওয়েবসাইট লাইক।
- `sql/07_require_approval.sql` : (v19) স্বয়ংক্রিয় প্রকাশ বন্ধ; সব জমা অ্যাডমিন অনুমোদনের পর প্রকাশ হয়।
- `src/app` : পাবলিক পেজ (হোম, মণ্ডপ, ম্যাপ, সময়সূচি, আর্কাইভ, জমা), লগইন, অ্যাডমিন প্যানেল।
- `.env.example` : দুটি env মানের নমুনা।

## env মান (Vercel-এ বসাতে হবে)

```
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
```

`service_role` চাবি কোথাও দেবেন না।

## নিজের কম্পিউটারে চালানো (ঐচ্ছিক)

```
cp .env.example .env.local   # মান বসান
npm install
npm run dev
```

## নিরাপত্তার মূল কথা

- আসল অনুমতি যাচাই হয় ডেটাবেসের RLS নিয়মে। অ্যাডমিন পাতা লুকিয়ে রাখার ওপর নির্ভর করা হয়নি।
- অ্যাডমিন হতে হলে `admins` টেবিলে নাম থাকতে হয়। সাধারণ Google ব্যবহারকারী নিজে থেকে সেখানে নাম লিখতে পারে না।
- জমা দেওয়া তথ্য `pending` থাকে, অ্যাডমিন অনুমোদন না দিলে প্রকাশ হয় না।

## আশেপাশের পূজা (v41)

- মণ্ডপের বিস্তারিত পাতার ম্যাপে ওই মণ্ডপ বড় লাল ॐ চিহ্নে, আর ৩ কিমির মধ্যের অন্য মণ্ডপ ছোট ॐ চিহ্নে দেখায়; নিচে "আশেপাশের পূজা" তালিকাও আছে।
- "আশেপাশের পূজাসহ Google Maps-এ দেখুন" বোতাম আপনার Google My Maps খোলে (`src/lib/myMaps.ts`)।
- অ্যাডমিন মেনু থেকে সব মণ্ডপের ফাইল নামিয়ে My Maps-এ Import করা যায় (v43-এ এটি KMZ, নিচে দেখুন)।

## ম্যাপ পাতা (v42, v43-এ বদলেছে)

## ম্যাপ পাতা ও KMZ (v43)

- `/map` পাতায় এখন শুধু আপনার Google My Maps (`mid=1NsBkf8AYv2m_gMkB-Hkk4xEz8OeWXa8`) দেখায়। সাইটের নিজের ম্যাপ এখান থেকে সরানো হয়েছে; মণ্ডপের বিস্তারিত পাতায় আশেপাশের পূজাসহ নিজের ম্যাপ আগের মতোই আছে।
- পাতায় "নতুন তথ্য যুক্ত করুন" বোতাম আছে; জমা দেওয়া তথ্য অ্যাডমিন যাচাইয়ের পর সাইটে আসে।
- অ্যাডমিন মেনুর "Google My Maps-এর জন্য KMZ (৩ লেয়ার)" (`/admin/map-export`) সব প্রকাশিত মণ্ডপের KMZ দেয়: মহানগর / উত্তর / দক্ষিণ চট্টগ্রাম আলাদা লেয়ারে, নিজস্ব ॐ পিনসহ। এলাকা না মিললে "নতুন যোগ হওয়া" নামে চতুর্থ লেয়ারে যায়।
- My Maps হালনাগাদ: নতুন KMZ নামান → My Maps-এ Add layer → Import → পুরোনো লেয়ার মুছুন। My Maps আপনা-আপনি ডাটাবেসের সঙ্গে মেলে না।
- `src/components/MapTabs.tsx` মুছে ফেলা হয়েছে (v42-এর ট্যাব আর লাগে না)।
